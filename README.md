# vkBot — бот-собеседник ВКонтакте на Vercel

Бот работает через **Callback API** сообщества ВК. Марина — виртуальный персонаж для лёгкого, уважительного знакомства: 27 лет, автомеханик из Санкт-Петербурга. Отвечает коротко, слегка флиртует без пошлости и честно говорит, что она виртуальная, если её об этом прямо спрашивают.

## Что умеет
- История последних сообщений загружается через `messages.getHistory` — отдельная база данных не нужна.
- Ответы генерируются через OpenRouter с бесплатными моделями по очереди и переходом к следующей модели при ошибке.
- Перед ответом бот показывает статус «печатает».
- `/start` — знакомство с Мариной
- `/help` — краткая справка
- `/id` — показать ID пользователя
- `/ping` — проверить, что бот на связи

## Установка

### 1. Настроить сообщество ВК
Включите сообщения сообщества и создайте ключ доступа с правом **«Сообщения сообщества»**. Включите Callback API и событие **«Входящее сообщение»**.

### 2. Настроить Vercel
Импортируйте репозиторий в Vercel и добавьте переменные окружения:

| Имя | Значение |
|---|---|
| `VK_TOKEN` | ключ доступа сообщества ВК |
| `OPENROUTER_API_KEY` | API-ключ OpenRouter |
| `VK_CONFIRMATION` | строка подтверждения; если не задана, используется `4809e6d1` |
| `VK_GROUP_ID` | ID сообщества; если не задан, используется `241266471` |
| `VK_SECRET` | секрет Callback API (не проверяется для события `confirmation`) |

Разверните проект. В настройках Callback API укажите адрес `https://ваш-проект.vercel.app/api/index`, версию API `5.199`, подтвердите адрес и включите входящие сообщения. Таймаут функции Vercel настроен на 60 секунд.
