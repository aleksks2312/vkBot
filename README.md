# vkBot — бот ВКонтакте на Vercel (Python)

Бот работает через **Callback API**: ВК присылает события на HTTPS-адрес,
который выдаёт Vercel. Постоянно запущенный сервер не нужен.

## Что умеет
- `/start` — приветствие
- `/help` — список команд
- `/id` — показать ID пользователя
- `/ping` — проверка
- любой другой текст — эхо

## Установка за 5 шагов

### 1. Создать сообщество ВК
Если ещё нет: https://vk.com/groups → «Создать сообщество».

### 2. Включить сообщения и получить токен
В сообществе: **Управление → Сообщения** → включить.
Затем **Управление → Настройки → Работа с API → Ключи доступа → Создать ключ**,
поставить галочки **«Сообщения сообщества»** и **«Управление сообществом»**.
Скопируйте ключ — это `VK_TOKEN`.

### 3. Задеплоить на Vercel
1. Зайдите на https://vercel.com → **Add New → Project** → импортируйте этот репозиторий с GitHub.
2. В разделе **Environment Variables** добавьте:
   | Имя | Значение |
   |---|---|
   | `VK_TOKEN` | ключ из шага 2 |
   | `VK_CONFIRMATION` | пока любое, заполним на шаге 4 |
   | `VK_SECRET` | любая придуманная строка |
   | `VK_GROUP_ID` | ID сообщества (число) |
3. Нажмите **Deploy**. Получите адрес вида `https://vk-bot-xxx.vercel.app`.

### 4. Подключить Callback API
В сообществе: **Управление → Настройки → Работа с API → Callback API**.
1. Версия API: `5.199`.
2. Адрес сервера: `https://ваш-проект.vercel.app/api/index`
3. Скопируйте «Строку, которую должен вернуть сервер» → в Vercel обновите
   переменную `VK_CONFIRMATION` (Settings → Environment Variables) и сделайте
   **Redeploy** (Deployments → ⋯ → Redeploy).
4. Нажмите **Подтвердить**.
5. В поле «Секретный ключ» введите то же, что в `VK_SECRET`, сохраните.
6. Вкладка **Типы событий** → включить **«Входящее сообщение»**.

### 5. Проверить
Напишите сообществу в личку `/start` — бот ответит.

## Локальная проверка
```bash
python3 tests/test_local.py
```

## Структура
```
api/index.py     — вся логика бота (serverless-функция)
vercel.json      — маршрутизация
.env.example     — пример переменных окружения
```

## Как добавить свою команду
В `api/index.py` найдите функцию `handle_command` и добавьте ветку:
```python
if cmd == "/hello":
    return "Привет-привет!"
```
Закоммитьте и запушьте — Vercel задеплоит автоматически.
